# CLAUDE.md — 历史粘贴板项目指引

## 项目概述
「历史粘贴板」是一个 Windows 桌面剪贴板历史管理软件。运行期间自动监听并记录用户复制的文字和图片，以时间降序卡片展示，支持搜索、置顶、删除和回贴。

## 工作说明

### 开发流程
1. 每次只开发一个模块，确保该模块功能正确后再进入下一个
2. 每完成一个模块，更新对应的开发日志
3. 遵循 [设计规范](docs/设计规范.md) 中的颜色、尺寸、字体要求
4. 按 [技术规范](docs/技术规范.md) 中的项目结构和数据存储方案实现
5. 完成后对照 [开发计划](docs/开发计划.md) 中的验证清单逐项测试

### 代码规范
- 使用中文注释说明关键逻辑（目标用户为中文用户）
- 变量和函数名使用英文小写+下划线（Python 惯例）
- UI 相关代码集中在 `main_window.py` 中
- 数据库操作封装在 `database.py` 中，不跨文件直接操作 SQL
- 线程安全：数据库写入使用 `threading.Lock` 保护

### 需求变更
- 先更新 [docs/需求文档.md](docs/需求文档.md)
- 再更新相关技术方案
- 最后修改代码

### 用户设定
- 用户是不懂编程的普通用户
- 运行方式：手动打开（非后台常驻）
- 技术方案：Python 轻量应用
- 交互：点击卡片复制到剪贴板
- 简洁解释技术决策，避免过度技术化
