# 历史粘贴板 — 需求文档

## 项目背景
用户在 Windows 电脑上日常办公时，经常需要回顾之前复制过的文字和图片。Windows 自带的剪贴板历史（Win+V）功能有限，需要一个更直观、可管理的剪贴板历史工具。

## 目标用户
- 不懂编程的普通用户
- 日常办公需要频繁复制粘贴的 Windows 用户

## 核心需求

### R1: 自动记录剪贴板
- 软件运行期间，自动监听并记录用户 Ctrl+C 复制的所有内容
- 支持文字（纯文本）和图片（位图）
- 相同内容不重复记录（去重）

### R2: 历史卡片展示
- 所有记录以卡片形式展示
- 按时间降序排列（最新的在最上面）
- 每张卡片显示：内容预览、时间戳
- 文字卡片：显示前 80 字预览
- 图片卡片：显示缩略图

### R3: 卡片操作
- **点击复制**：点击卡片后，内容复制回剪贴板，用户可在任意位置 Ctrl+V 粘贴
- **置顶**：点击📌按钮将卡片置顶，置顶卡片始终显示在最上方，带淡蓝色高亮
- **删除**：点击🗑按钮删除单条记录（需确认）
- **双击**：双击卡片快速复制并自动最小化窗口

### R4: 搜索功能
- 顶部搜索框，实时过滤
- 仅匹配文字内容（图片按时间筛选即可）

### R5: 保留期限设置
- 用户可设定历史记录的保留天数：1天 / 3天 / 5天 / 不限
- 超过期限的记录自动删除（包括关联的图片文件）
- 置顶的记录不受期限影响

### R6: UI 设计要求
- 整体风格：简洁、直观
- 主色调：淡蓝色 (#B3D9FF 系)
- 圆角卡片设计
- 窗口默认大小：500×700 像素
- 可调整窗口大小

### R7: 运行方式
- 手动打开使用，关闭即退出
- 不需要后台常驻或开机自启
- 打开期间自动监听剪贴板

## 非功能性需求
- 数据存储在用户本地 `%APPDATA%\ClipHistory\`
- 单实例运行（不允许重复打开）
- 启动速度快（<2秒）
- 内存占用低（<100MB）
