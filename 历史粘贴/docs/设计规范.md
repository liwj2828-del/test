# 历史粘贴板 — 设计规范

## 设计原则
- **简洁**：减少不必要的 UI 元素，一目了然
- **直观**：不需要说明书就能上手使用
- **一致**：统一的颜色、间距、圆角、字体

## 色彩系统

| 用途 | 颜色值 | 色卡 |
|------|--------|------|
| 主色调（淡蓝） | #A8D8EA | 卡片高亮、按钮主色 |
| 主色调深色 | #7CB8D0 | 按钮 hover 状态 |
| 置顶卡片背景 | #D6EEF5 | 置顶卡片区分色 |
| 普通卡片背景 | #FFFFFF | 默认卡片背景 |
| 窗口背景 | #F0F5F8 | 整体窗口底色 |
| 文字主色 | #333333 | 正文文字 |
| 文字次要 | #888888 | 时间戳、提示文字 |
| 搜索框边框 | #CCCCCC | 未聚焦状态 |
| 搜索框聚焦 | #A8D8EA | 聚焦状态边框 |
| 删除按钮 | #FF6B6B | 悬停删除 |
| 置顶按钮 | #A8D8EA | 激活状态 |

## 组件规范

### 搜索框
- 圆角输入框
- 左侧搜索图标 "🔍"
- placeholder："搜索复制过的内容..."
- 输入时实时过滤卡片列表
- 无匹配结果显示"没有找到相关内容"

### 卡片
- 白色背景，圆角 10px
- 轻微阴影或边框（1px #E0E0E0）
- 悬停时显示操作按钮
- 点击有轻微颜色变化反馈

### 置顶卡片
- 淡蓝色背景 (#D6EEF5)
- 与其他卡片之间有分隔
- 始终排列在最上方
- 📌 按钮显示为实心状态

### 设置按钮
- 齿轮图标 "⚙"
- 位于搜索框右侧
- 点击弹出设置面板（或新窗口）

### 设置面板
- 标题："设置"
- 保留期限：下拉选择（1天 / 3天 / 5天 / 不限）
- 保存按钮

### 确认对话框
- 删除操作必须弹出确认
- 标题："确认删除"
- 内容："确定要删除这条记录吗？"
- 按钮："取消" / "确认删除"
- 确认按钮红色

## 交互反馈
- 点击卡片复制 → 短暂 Toast 提示"已复制到剪贴板"（2秒后自动消失）
- 置顶/取消置顶 → 卡片位置立即变化
- 删除 → 确认后卡片移除，列表刷新
- 设置保存 → Toast 提示"设置已保存"
