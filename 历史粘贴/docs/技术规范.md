## 数据存储

### 数据库位置
`%APPDATA%\ClipHistory\history.db`

### 数据库结构
```sql
CREATE TABLE IF NOT EXISTS history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    content_type TEXT NOT NULL CHECK(content_type IN ('text', 'image')),
    text_content TEXT,
    image_path TEXT,
    timestamp TEXT NOT NULL,
    pinned INTEGER DEFAULT 0
);

CREATE INDEX IF NOT EXISTS idx_timestamp ON history(timestamp DESC);
CREATE INDEX IF NOT EXISTS idx_pinned ON history(pinned);
```

### 图片存储
`%APPDATA%\ClipHistory\images\` 目录
- 文件名格式：`{timestamp}_{hash}.png`
- 数据库中 `image_path` 存储相对路径

### 设置文件
`%APPDATA%\ClipHistory\settings.json`
```json
{
    "retention_days": 3
}
```

## 剪贴板监听设计

### 文字监听
- 使用 `pyperclip.paste()` 获取当前剪贴板文字
- 每 500ms 轮询一次
- 与上次记录对比，相同则跳过

### 图片监听
- 使用 `PIL.ImageGrab.grabclipboard()` 获取剪贴板图片
- 如果返回非 None 且为 Image 对象，则为新图片
- 保存为 PNG 文件，记录路径到数据库

### 线程安全
- 剪贴板监听在独立线程中运行
- 数据库写入使用线程锁保护
- UI 刷新通过 `after()` 方法在主线程调度

## 打包配置

```bash
pyinstaller --onefile --windowed --name "历史粘贴板" main.py
```
