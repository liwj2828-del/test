# 历史粘贴板 — 开发计划

## 开发原则
- **稳步推进**：每次只完成一个模块，确保该模块功能正确后再进入下一个
- **可验证**：每个模块完成后有明确的验证标准
- **文档同步**：开发日志每日更新，记录完成事项和待办事项

## 开发阶段

### 第 1 天：项目基础架构
- [ ] 创建项目文件夹结构
- [ ] 编写需求文档、技术规范、设计规范
- [ ] 编写 CLAUDE.md 项目指引
- [ ] 安装 Python 依赖
- [ ] 验证：所有文档就绪，依赖安装成功

### 第 2 天：数据层
- [ ] 实现 `database.py`：数据库初始化、CRUD、自动清理
- [ ] 实现 `settings.py`：设置读写
- [ ] 验证：运行 `database.py` 测试，确认数据库创建和基本操作正常

### 第 3 天：剪贴板监听
- [ ] 实现 `clipboard_monitor.py`：文字监听、图片监听、去重
- [ ] 验证：运行监听模块，复制文字和图片，确认数据库有记录

### 第 4 天：UI 主界面
- [ ] 实现 `main_window.py`：窗口框架、卡片列表、搜索框、设置面板
- [ ] 验证：启动 UI，确认布局符合设计规范

### 第 5 天：整合与调试
- [ ] 实现 `main.py`：单实例检查、线程管理、UI 启动
- [ ] 全功能联调测试
- [ ] 验证：按验证清单逐项测试

### 第 6 天：打包与交付
- [ ] 编写 `build.bat`
- [ ] PyInstaller 打包
- [ ] 在干净环境测试 exe 运行
- [ ] 验证：exe 文件可独立运行，功能完整

## 验证清单
