# 历史粘贴板

> Windows 剪贴板历史管理软件 — 记录你复制过的所有文字和图片。

## 使用方法

### 直接运行（推荐）

双击 `dist/历史粘贴板.exe` 即可启动。

### 源码运行

```bash
pip install -r requirements.txt
python main.py
```

## 功能

| 功能 | 说明 |
|------|------|
| 🔍 自动记录 | 打开软件后，自动记录所有 Ctrl+C 复制的内容 |
| 📝 文字 + 图片 | 支持文字和图片两种格式 |
| 📌 置顶 | 重要内容置顶，始终排在最前 |
| 🗑 删除 | 不需要的记录一键删除 |
| 🔎 搜索 | 输入关键词实时搜索历史 |
| ⏱ 保留期限 | 可设置 1天 / 3天 / 5天 / 不限 |

## 操作

- **单击卡片** → 复制到剪贴板
- **双击卡片** → 复制并最小化窗口
- **📌 按钮** → 置顶 / 取消置顶
- **🗑 按钮** → 删除记录

## 数据存储

所有数据存储在本地 `%APPDATA%\ClipHistory\` 目录，不上传网络。

## 系统要求

- Windows 10 或更高版本
- 无需安装 Python
